# Student Management System (C++)

A console-based Student Management System built using C++ and Object-Oriented Programming concepts.

## Features

* Add Student
* Display All Students
* Search Student by Roll Number
* Update Student Details
* Delete Student Records

## Concepts Used

* Classes and Objects
* Encapsulation
* Arrays of Objects
* Functions
* Loops and Conditional Statements

## How to Run

Compile:

```bash
g++ student_management_system.cpp -o student
```

Run:

```bash
./student
```
